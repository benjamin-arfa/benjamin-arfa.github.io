Engineering that survives the audit

03 — Selected work

Open source and production

01

Maintainer · GovTech

swiss-law-as-source

Swiss federal law as machine-readable source

Publishes Swiss legal texts as structured, version-controlled source data, so legislation can be queried, diffed and consumed by software the way code is. Built in the open, following the law-as-code approach developed through the Open Legal Lab.

Legal dataOpen dataPython

02

Maintainer · GovTech

consultaition

Swiss federal consultation report generator

Automates the creation of Swiss federal Ergebnisbericht reports from structured Excel data. Vendor-agnostic LLM optimisation tuned on authentic federal consultation data, with an interactive editor for paragraph-by-paragraph refinement. German, French and Italian.

PythonFastAPILLM

03

Contributor · RegTech

Eclipse FreeBIRD tools

Tooling to democratise BIRD as an open standard

An open-source toolkit for the Banks' Integrated Reporting Dictionary, the standard European banks use to supply data to supervisory bodies. GUI toolkit for dictionaries and mappings, Docker containerisation, validation and APIs.
